==============================================================================
adb（Linux ARM64）第三方软件声明
astrbot_phone_control 随包二进制
==============================================================================

本目录中的 adb 是面向 Linux ARM64（aarch64）的自包含运行时，由 Debian 12
（bookworm / bookworm-backports）arm64 二进制包重新打包，随 AstrBot 插件分发。
Google 未发布 Linux ARM64 版官方 platform-tools，因此本目录不是 Google 官方
Linux ARM64 platform-tools 构建。

一、adb 主程序
  上游项目 : Android Open Source Project — android-platform-tools 34.0.5
  Debian 包: adb 1:34.0.5-12~bpo12+1（arm64）
  包文件名 : adb_34.0.5-12~bpo12+1_arm64.deb
  来源     : bookworm-backports
  下载地址 : https://deb.debian.org/debian/pool/main/a/android-platform-tools/adb_34.0.5-12~bpo12+1_arm64.deb
  许可     : Apache-2.0（adb 内含的 AOSP 第三方组件按其各自许可，详见上游 NOTICE）
  文件     : lib/adb-bin
  SHA-256  : 563ea34db5b218f8861c4eebcf796be3e69e95221eb687d958447fff75d7daf4
  入口     : adb（POSIX sh 包装脚本，设置 LD_LIBRARY_PATH 后执行 lib/adb-bin）
